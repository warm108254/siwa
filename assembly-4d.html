💡 หลักการที่ใช้

วิดีโอลำดับก่อสร้างทุกตัวใช้หลักเดียวกัน — ไม่ได้ "เคลื่อนย้าย" วัตถุ แต่ "เปิด/ปิดการมองเห็น" ตามลำดับ

1. แตกงานเป็น object ย่อยตามขั้นตอนจริง
2. โมเดลงานชั่วคราวเป็น object จริง — แบบหล่อ ค้ำยัน เหล็กหนวดกุ้ง
3. ใส่ค่า “ขั้นที่เท่าไร” ให้ทุก object
4. ไล่ขั้น → เปิด object ของขั้นนั้น / ปิดแบบหล่อเมื่อถอด
5. ตรึงกล้อง แล้ว render ออกเป็นวิดีโอ
