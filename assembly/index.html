🏗️ Assembly Object — คิดปริมาณงานก่อสร้างจากโมเดล

แตกวัตถุในโมเดลตาม “ลำดับการก่อสร้างจริง” แทนการโมเดลตามรูปทรงที่ออกแบบ แล้วดึงปริมาณ ลำดับงาน และรูปประกอบออกมาจากโมเดลชุดเดียวกัน
กฎทองที่เครื่องมือทุกตัวใช้ร่วมกัน — 1 Object = 1 การเทคอนกรีต = 1 กิจกรรมในแผนงาน = 1 ครั้งที่ตรวจรับงาน
ขอบเขตของ object คือ รอยต่อการเทจริง (construction joint) ไม่ใช่รูปทรงตามแบบออกแบบ

แยกชั้นวัตถุ (Static Layers)

ภาพนิ่ง · Exploded view

โมเดลนิ่งที่ทุก object เป็นเลเยอร์ เปิด/ปิดและดึงแยกออกจากกันได้

  • แยกตามชนิดงาน / ระดับ / ลำดับก่อสร้าง
  • คอนกรีตโปร่งแสง (X-ray) เห็นเหล็กข้างใน
  • ดูเฉพาะ “งานชั่วคราว” ที่ไม่มีรูปในแบบ
  • บันทึกเป็นภาพ PNG พร้อมป้ายกำกับ
เปิดเครื่องมือ →

ใช้ร่วมกันยังไง

1 · กำหนดขนาดกรอกขนาดฐานราก เสาตอม่อ คานหัวเสา และกฎการแตกวัตถุ (จำนวนชั้นเท / ความสูงแบบต่อครั้ง) — ใช้ค่าชุดเดียวกันได้ทั้งสามเครื่องมือ
2 · ได้ปริมาณหน้า QTO คำนวณคอนกรีต แบบหล่อ เหล็กเสริม งานดิน พร้อม BOQ และแผนงาน
3 · ได้รูปประกอบหน้า 4D ให้วิดีโอลำดับก่อสร้าง · หน้า Layers ให้ภาพนิ่งแยกชั้นสำหรับใส่ในเอกสารวิธีการทำงาน

หลักการ 7 ขั้นตอน

STEP 1
กฎการแตกวัตถุ
โมเดลตามที่จะสร้าง ไม่ใช่ตามที่ออกแบบ
STEP 2
ลำดับชั้น Assembly
Project → Zone → Structure → Assembly → Part
STEP 3
กฎการตัดกัน
กันปริมาตรซ้อนทับ ที่ทำให้คอนกรีตเกินจริง 3–8%
STEP 4
วัตถุที่ไม่มีในแบบ
แบบหล่อ งานดิน รอยต่อ นั่งร้าน = derived object
STEP 5
ผูก Property
WBS · Pay item · Spec · Activity ID · %เผื่อ
STEP 6
เชื่อม 4D และ 5D
Object ↔ Activity ↔ Cost
STEP 7
ปรับเทียบ + ล็อก Baseline
ต่างจากถอดแบบมือไม่เกิน ±3–5%
อ่านคำอธิบายเต็มของแต่ละขั้นได้ในหน้า คิดปริมาณ (กดที่การ์ด STEP เพื่อเปิดอ่าน)
ทุกเครื่องมือทำงานในเบราว์เซอร์ ไม่ส่งข้อมูลออกไปไหน · รองรับมือถือ
